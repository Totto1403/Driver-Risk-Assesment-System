## 📂 Dataset

**Kaggle Link:**
https://www.kaggle.com/datasets/banudeep/nthuddd2/data

### 📥 Setup Instructions

1. Download `train_data`

2. Extract the following folders:

   * `drowsy`
   * `notdrowsy`

3. Place them in:

```
dataset/
drowsiness/Training_Evaluation_Dataset/
```

4. Inside `Training_Evaluation_Dataset/`, rename:

```
drowsy     → 001
notdrowsy  → 002
```
